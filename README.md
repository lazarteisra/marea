# Marea

App personal de finanzas: cuánto puedes gastar hoy y registro de gastos con
el monto y tres toques.

- App web instalable (PWA), pensada para el celular.
- **Los datos viven solo en el dispositivo** (IndexedDB). Este repositorio
  contiene únicamente el código; nada de lo que se registra sale del teléfono.
- Sin framework, sin dependencias y sin paso de compilación.

Fuentes: Bodoni Moda y Hanken Grotesk, bajo la licencia SIL Open Font
License 1.1.
